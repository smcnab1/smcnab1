## Featured projects

### [SimHQ](https://simhq.app)

**Software for running healthcare simulation services.**

A SaaS platform I'm building to bring simulation operations into one place - including rooms, resources, assets, team workflows and organisational management.

[Website](https://simhq.app)

### [Pokelet](https://github.com/smcnab1/pokelet)

**A little personality for your Mac cursor.**

A free, open-source macOS app with four animated pointer characters, custom colours, sizes and click effects. Built to be lightweight, playful and privacy-conscious.

[Download](https://github.com/smcnab1/pokelet/releases) · [Website](https://smcnab1.github.io/pokelet/) · [Source code](https://github.com/smcnab1/pokelet)

### [SimuGen](https://github.com/smcnab1/SimuGen)

**Clinical simulation scenario design with ChatGPT.**

An open-source ChatGPT plugin that helps healthcare educators create structured scenarios with patient presentations, learning objectives, clinical progression, faculty guidance and debrief questions.

[Website](https://smcnab1.github.io/SimuGen/) · [Source code](https://github.com/smcnab1/SimuGen)
